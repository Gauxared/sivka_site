# Развертывание проекта на другом ПК

## Требования
- `Node.js` 20+ (рекомендуется LTS)
- `npm` (обычно идет вместе с Node.js)

## Быстрый запуск
1. Распакуйте архив проекта в любую папку.
2. Откройте терминал в папке проекта.
3. Установите зависимости:
   - `npm install`
4. Запустите проект в режиме разработки:
   - `npm run dev`
5. Откройте адрес из терминала (обычно `http://127.0.0.1:5173` или `http://localhost:5173`).

## Продакшн-сборка (опционально)
1. `npm run build`
2. `npm run preview`

## Что в архиве
- Исходный код (`src`, `public`, конфиги, `package.json`, `package-lock.json`)
- Материалы диплома (`diploma_work`)

## Что исключено из архива
- `node_modules` (восстанавливается командой `npm install`)
- `dist` (пересобирается командой `npm run build`)
